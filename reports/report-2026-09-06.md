### 🔴 CRITICAL — `CVE-2026-59822`

**BerriAI LiteLLM Improper Authentication Vulnerability** — BerriAI / LiteLLM

📅 Added to KEV: 2026-09-02 · ⏳ CISA due date: 2026-09-16 · 💀 Ransomware: Unknown

#### Executive summary

An improper authentication vulnerability in BerriAI LiteLLM allows an unauthenticated attacker to establish an authenticated session using an arbitrary Bearer token via the MCP Streamable HTTP endpoint. This critical flaw enables unauthorized access and potential system compromise without requiring legitimate credentials. Organizations must take immediate action to apply mitigations or discontinue use of the product.

#### Affected technologies

BerriAI, LiteLLM

#### Recommended actions

  1. Immediately apply all vendor-provided patches or mitigations for BerriAI LiteLLM, focusing on the MCP Streamable HTTP endpoint.
  2. If mitigations are not available, discontinue the use of BerriAI LiteLLM in your environment.
  3. Evaluate the internet exposure of all LiteLLM assets and prioritize remediation efforts in accordance with CISA’s BOD 26-04 guidance.
  4. Perform forensic triage on any potentially exposed or affected instances to identify signs of exploitation, following CISA’s "Forensics Triage Requirements".

#### Rationale

_This vulnerability is classified as critical because it allows an unauthenticated attacker to bypass authentication entirely and establish an authenticated session using an arbitrary token. This severe access bypass poses an immediate and direct risk of unauthorized system control, data compromise, or further network penetration. Its presence in the CISA KEV catalog confirms active exploitation, necessitating an urgent response._
