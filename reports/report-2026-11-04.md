#### Executive summary

This exploit occurs during the software upgrade process, leveraging predictable and web-accessible staging paths. Given its presence in CISA's KEV catalog, this vulnerability is known to be actively exploited, necessitating urgent attention.

WordPress, WordPress Core

  1. Apply all vendor-provided security updates and mitigations for WordPress Core immediately, prioritizing internet-facing installations.

  3. For WordPress deployments in cloud services, follow applicable BOD 26-04 guidance; if mitigations are not available, discontinue product use.
  4. Evaluate the internet exposure of all WordPress assets to inform and prioritize patching efforts according to BOD 26-04 guidelines.

#### Rationale

_The vulnerability is classified as critical due to the potential for unauthenticated remote code execution (RCE) on the server. Its inclusion in the CISA KEV catalog confirms active exploitation in the wild, presenting an immediate and severe risk. The exploit leverages a race condition during the upgrade window, which is a significant window of opportunity for attackers._
