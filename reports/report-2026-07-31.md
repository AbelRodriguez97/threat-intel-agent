### 🟠 HIGH — `CVE-2025-68686`

**Fortinet FortiOS Exposure of Sensitive Information to an Unauthorized Actor Vulnerability** — Fortinet / FortiOS

📅 Added to KEV: 2026-07-27 · ⏳ CISA due date: 2026-08-10 · 💀 Ransomware: Unknown

#### Executive summary

Fortinet FortiOS contains a vulnerability that allows an attacker to bypass a previously developed patch intended to prevent persistent access after a system compromise. This means if a system has already been breached through another vulnerability, the attacker could more easily maintain or re-establish control despite remediation efforts. This vulnerability requires an initial compromise at the filesystem level to be exploited.

#### Affected technologies

Fortinet FortiOS

#### Recommended actions

  1. Immediately apply all available mitigations and security updates from Fortinet for FortiOS that address CVE-2025-68686.
  2. Comply with CISA’s BOD 26-04 guidance for prioritizing security updates based on risk, evaluating each asset's internet exposure and ensuring adherence to patching guidelines.
  3. Implement CISA’s “Forensics Triage Requirements” to investigate potential compromise, especially if Fortinet FortiOS instances are exposed or were previously compromised.
  4. For cloud services, follow applicable BOD 26-04 guidance; if mitigations are unavailable, discontinue use of the product.

#### Rationale

_This vulnerability is classified as high severity because it is actively exploited in the wild, as indicated by its inclusion in the CISA KEV catalog. While it requires a prior compromise to be leveraged, its ability to bypass a patch designed to prevent post-exploitation persistence significantly increases an attacker's capability to maintain long-term access and control over a compromised system, complicating incident response and recovery efforts._
